# Function: useDevice()

### device

> **device**: `ComputedRef`\<`"mobile"` \| `"tablet"` \| `"desktop"`\>

### isDesktop

> **isDesktop**: `ComputedRef`\<`boolean`\>

是否为桌面端（≥ 992px）

### isMobile

> **isMobile**: `ComputedRef`\<`boolean`\>

是否为移动端（&lt; 768px）

### isTablet

&gt;` **isTablet**: `ComputedRef`\<`boolean`\>

是否为平板端（&lt; 992px）

### width

&gt;` **width**: `Ref`\<`number`, `number`\> = `currentWidth`

当前窗口宽度（只读）
